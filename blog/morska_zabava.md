
Како мапирати садржаје намењене туристима током летње сезоне?

туш:
```
amenity=shower
outdoor=yes
seasonal=yes
fee=no
hot_water=no
```
кабина за пресвлачење:
```
amenity=dressing_room
seasonal=yes
```
степенице за улазак у море:
```
highway=ladder
material=metal
access=yes
seasonal=yes
tidal=yes
```
плажа:
https://wiki.openstreetmap.org/wiki/Talk:Tag:natural%3Dbeach
https://wiki.openstreetmap.org/wiki/Tag:leisure%3Dbeach_resort
```
natural=beach
```
ако је уређена:
```
leisure=beach_resort
```
понта:
```
surface=concrete
```
камење:
```
surface=pebblestone
```
песак:
```
surface=sand
```
