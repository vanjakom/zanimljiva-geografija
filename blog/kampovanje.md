trek-mate tag #camp za camp_site i caravan_site
постоје две ознаке, камп у традиционалном смислу:
```
tourism = camp_site
```
и преноћиште за кампере / приколице:
```
tourism=caravan_site
```
користити:
```
tents = yes/no
caravans = yes/no
motorhome = yes/no
```

рецепција:
```
amenity = reception_desk
```
неко обележава са 
```
information = office
tourism = information
```

```
tourism = camp_pitch
